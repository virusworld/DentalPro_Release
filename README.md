# DentalPro 🦷

DentalPro is an advanced, production-ready Dental Clinic Management System built with a robust Go backend and a modern React/Vite frontend. It provides a complete suite of tools for managing patients, doctors, appointments, and clinic finances.

## 🚀 Key Features

*   **Clinical Management:** Comprehensive patient profiles, medical history, dynamic treatment plans, and prescriptions.
*   **Appointment Scheduling:** Interactive calendar with drag-and-drop support, status tracking, and doctor-specific views.
*   **Financial & Billing:** Robust invoicing system, multi-payment support, expense tracking, and cash drawer management.
*   **Inventory Control:** Track dental supplies, receive low-stock alerts, and log usage directly to patient treatments.
*   **Analytics & Reporting:** Real-time dashboard and detailed reports for clinic revenue, doctor performance, and system audits.
*   **Security & Access Control:** Role-Based Access Control (RBAC), cryptographically signed software licensing, JWT authentication, and detailed audit logging.
*   **Localization:** Built-in multi-language support (English and Arabic with full RTL layout).

## 🛠️ Technology Stack

*   **Backend:** Go (Golang), Gin Web Framework, GORM, SQLite (Auto-migrating).
*   **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Zustand (State Management), React Router.
*   **Deployment:** The entire application (including the built frontend React app) compiles down into a **single, standalone executable file** for zero-dependency deployment on Windows.

## 📦 Running the Application

### Production
Simply download the latest `dentalclinic.exe` from the [Releases](https://github.com/virusworld/DentalPro_Release/releases) page and run it. The SQLite database will be automatically created and seeded on the first run.
